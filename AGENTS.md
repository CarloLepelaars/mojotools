# mojotools

This project is about providing simple tools to make Mojo programming easier, more fun and more maintainable. These implementations are similar to AnswerAI's [fastcore](https://fastcore.fast.ai/) library. Refer to the [fastai style guide](https://docs.fast.ai/dev/style.html) for more information on coding principles.

This is a Mojo source project (NOT Python). Dependencies are managed with `uv`;
`pyproject.toml` requires Python >=3.14 and Mojo >=1.1.0.

`./quality.sh` runs the test suite.
