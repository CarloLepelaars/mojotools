# mojotools

Basic tools to make your Mojo code easier and more maintainable.

## Install

Mojo packages are not on PyPI. They live on
[modular-community](https://prefix.dev/channels/modular-community)
(a conda channel on prefix.dev).

Add the channel to your `pixi.toml`, then:

```bash
pixi add mojotools
```

## Tests

```bash
./quality.sh
```
